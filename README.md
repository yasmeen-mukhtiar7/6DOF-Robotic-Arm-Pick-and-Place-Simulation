# Robotic Arm Pick-and-Place Simulation

## CodeAlpha Robotics & Automation Internship — Task 2

This repository contains a robotic arm simulation project developed using CoppeliaSim for the CodeAlpha Robotics & Automation Internship Program.

## Project Overview

The project demonstrates a 6-DOF robotic arm performing a basic pick-and-place operation in a simulated environment. The robotic arm is capable of moving objects between defined positions using programmed joint motion and end-effector control.

## Objectives

- Design a robotic arm simulation
- Define robot degrees of freedom (DOF)
- Perform pick-and-place operation
- Demonstrate robotic motion control in simulation

## Software Used

- CoppeliaSim EDU
- Robotics Simulation Environment

## Robot Specifications

- Robot Type: Industrial Robotic Arm
- Degrees of Freedom (DOF): 6
- Operation: Pick and Place
- Control Method: Joint-based motion control

## Features

- 3D robotic arm simulation
- Pick-and-place movement
- Joint motion demonstration
- Industrial robotics workflow
- End-effector object handling
